## Getting Started:
Per scaricare l'applicazione vai in [Releases](https://github.com/KemonoBAT4/MastroDiChiavi/releases) e scarica i file necessari.
Una volta scaricate le applicazioni, prima ancora di eseguire il primo accesso, verrà chiesto l'`URL` base di connessione al server per eseguire le chiamate `API`.
<!-- In caso di necessità è possibile configurare più `"profili"` locali slegati l'uno dall'altro in caso si abbia bisogno di interfacciarsi a uno o server diversi, senza dover riconfigurare tutto ogni volta.
Dopodichè sarà possibile eseguire il primo accesso all'interno dell'applicazione e iniziare la navigazione.
Inoltre, una pagina web dedicata alla configurazione del server è disponibile all'indirizzo `http://<server_ip_address>:8000/server/home`.
Il backend renderà disponibile di default la versione web dell'applicazione, in caso le versioni `Desktop` o `Mobile` non fossero disponibili per il sistema operativo desiderato. -->
